NB1 vs NB2 – Strukturális összehasonlítás

A két liga eltérése quality-csoportonként

Az oszlopok az átlagos abszolút Cohen’s d értéket mutatják az adott csoporton belüli KPI-k alapján. Minél nagyobb az érték, annál inkább különbözik a két liga az adott dimenzióban. (0.2 = kis, 0.5 = közepes, 0.8 = nagy eltérés)

KPI-szintű részletek

Minden KPI Cohen’s d értéke, d szerint rendezve. Pozitív = NB1 magasabb átlag, negatív = NB2 magasabb átlag. Szín = quality-csoport.

Kék = NB1 magasabb  |  Piros = NB2 magasabb. Cohen's d: 0.2 = kis, 0.5 = közepes, 0.8 = nagy eltérés. 2025–26-os szezon, liganként átlagolt csapatértékek alapján.
